Homebrew Tap
============

This is a homebrew tap for the following projects:

| Project | Description | Version | Commands |
|---------|-------------|---------|----------|
| [ai-cli-tools](https://github.com/Kuniwak/ai-cli-tools) | CLI Tools for CLI AI Agents | 3.0.1 | `stdinexec`, `stdinsubst`, `stdinsplit`, `stdinsub` |
| [pfd-tools](https://github.com/Kuniwak/pfd-tools) | Tools related to Process Flow Diagram (PFD) such as static analyzers and schedulers | 4.0.4 | `pfdlint`, `pfdtable`, `pfdrenum`, `pfdplan`, `pfddiff`, `pfdquery`, `pfdrun`, `pfdparse`, `pfdrungraph`, `pfddot`, `pfddeadlock`, `bizday`, `planmaster`, `plantimeline`, `holidays`, `criticalpath` |
| [puml-tools](https://github.com/Kuniwak/puml-tools) | A suite of tools for viewing, editing and searching PlantUML diagrams | 3.2.0 | `pumlc42seqchk`, `pumlc4bdyls`, `pumlc4fold`, `pumlhelp`, `pumlparse`, `pumlseq2c4`, `pumlseqbreak`, `pumlseqexpand`, `pumlseqfold`, `pumlseqgroupcut`, `pumlseqgroupmask`, `pumlseqgroupsplit`, `pumlseqhide`, `pumlseqmsg`, `pumlseqproj`, `pumlseqrefinement`, `pumlseqsubset`, `pumlseqtrace`, `pumltodo` |

How to install
--------------

### By Tapping the Repository

```console
$ brew tap Kuniwak/tap
$ brew install ai-cli-tools
$ brew install pfd-tools
$ brew install puml-tools
```


### By Installing the Formulae Directly

```console
$ brew install Kuniwak/tap/ai-cli-tools
$ brew install Kuniwak/tap/pfd-tools
$ brew install Kuniwak/tap/puml-tools
```
