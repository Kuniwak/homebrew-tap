Homebrew Tap
============

This is a homebrew tap for the following projects:

| Project | Description | Version | Commands |
|---------|-------------|---------|----------|
| [ai-cli-tools](https://github.com/Kuniwak/ai-cli-tools) | CLI Tools for CLI AI Agents | 3.0.0 | `stdinexec`, `stdinsubst`, `stdinsplit`, `stdinsub` |
| [pfd-tools](https://github.com/Kuniwak/pfd-tools) | Tools related to Process Flow Diagram (PFD) such as static analyzers and schedulers | 4.0.3 | `pfdlint`, `pfdtable`, `pfdrenum`, `pfdplan`, `pfddiff`, `pfdquery`, `bizday`, `planmaster`, `plantimeline`, `holidays`, `criticalpath` |
